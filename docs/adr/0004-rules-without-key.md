# 无 Key 走规则

## 背景

面试和 CI 不能依赖外网 Key。模型挂了也不应该让整张图失败。

## 决策

`LLM_PROVIDER=none` 或 Key 为空时，intake / decompose / 修复走确定性规则。结构化调用失败返回 `None`，hybrid 模式留下规则底稿；仅 LLM 模式得到空草案而不是抛到 API 外。

## 取舍

规则漏检复姓、英文名、弱动词和「推进」一词多义。这些在 hard 集里上报，不写成 CI 失败。有 Key 时模型结果与规则底稿合并，而不是整表替换。

## 后果

黄金集门槛衡量的是规则路径回归，不是 DeepSeek 的抽取质量。
