# 工具循环三重刹车

## 背景

有 Key 时 `validate_repair` 由模型决定调用校验、修复和删除。没有上限就会空转，SSE 一直不结束。

## 决策

三道停机：往返不超过 `max_tool_rounds`（4），连续失败不超过 2，error 数不下降（stall）不超过 2。停下后再做一次最终 validate。无 Key 仍是规则修复，最多 2 次，不修负责人。

## 取舍

复杂纪要可能修不干净。带着剩余 ERROR 进入审核，由人拍板，而不是在图里无限 interrupt。

## 后果

超时不在这一层重试。传输层 429/5xx 另有次数和睡眠预算，避免 4 轮工具调用乘上多次超时把请求挂到数分钟。
